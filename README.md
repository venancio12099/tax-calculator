# Tax Calculator 
A command line program that I made in Python, works out how much income tax a UK employee pays and what their net pay would be.

## How It Works
Just enter your name, company and salary and it will print a payslip with your details, tax band and net pay.

## Tax Bands
- Up to £12,500 ----> 0% (Personal Allowance) 
- Between £12,500 - £50,000 ----> 20% (Basic Rate) 
- Between £50,000 - £150,000 ----> 40% (Higher Rate)
- Over £150,000 ----> 45% (Additional Rate) /n

## How to run it
```bash
python tax_calculator.py
```
